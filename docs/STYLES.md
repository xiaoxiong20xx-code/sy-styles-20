# 20 种风格一览

每个风格都是 `styles/编号-名字/index.html` 一个文件，用 Chrome 直接打开就能循环预览。

| 编号 | 风格 | 画面 | 技术 |
|---|---|---|---|
| 01 | 逐帧手绘（FRAME BY FRAME） | 先用蓝铅笔起稿，再描线、铺水彩，一秒重画 12 张。镜头一动才发现，整幅画是立体的。 | 铅笔起稿、水彩晕染、一拍二 12fps |
| 02 | 等轴 2.5D（ISOMETRIC） | 一座悬浮的小城：道路自己画出来，楼房一圈圈弹起，车在跑、云影在走。太阳落山，窗户和路灯一盏盏亮起。 | 正交投影、昼夜光影、镜头环绕 |
| 03 | 扁平矢量（FLAT VECTOR） | 一镜到底的无限推进：手里的手机→屏幕里的城市→亮灯的窗→房间里的电脑→剪辑软件里，又是那只手。 | 无限缩放、矢量插画、无缝循环 |
| 04 | 线条动画（LINE ART） | 九百根金色细线像丝绸一样随风飘，再排成连绵的山脊。镜头向前滑行，太阳升起，一束光沿山路走到最远的山顶。 | 九百根线、透视山脊、镜头滑行 |
| 05 | 3D 渲染（3D RENDER） | 粉彩摄影棚里，糖果方块落下搭成领奖台，金环像欧拉盘一样转着落定，玻璃珠滚过，镜面球最后登顶。 | 光线步进、玻璃折射焦散、景深 |
| 06 | 形变动画（SHAPE MORPH） | 七千个光点在三维空间里漂浮，一次次变形：想法→灯泡→作品→播放键→爆款，每次都卷起一阵气流。 | 7000 粒子、旋度噪声、弹性落定 |
| 07 | 贴纸风科普（STICKER EXPLAINER） | 切割垫上，一张张模切贴纸啪地贴下：白边、反光、落下时收紧的影子。马克笔箭头串起步骤，讲清一条视频怎么火。 | 模切贴纸、反光扫过、镜头巡游 |
| 08 | 赛博朋克 HUD（CYBERPUNK HUD） | 无人机飞进一座激光雷达点云城市，扫描波一圈圈点亮街区。全套飞行 HUD：罗盘、高度速度带、雷达，最后锁定一辆飞车。 | LiDAR 点云、飞行 HUD、目标锁定 |
| 09 | 拼贴剪贴（COLLAGE CUT-OUT） | 牛皮纸上一张张撕下、剪好、贴上：杂志字、网点印刷、拍立得、压纹标签和红印章。最后夕阳带着树影扫过桌面。 | 撕纸纤维、真实光影、定格 12fps |
| 10 | 弥散渐变 玻璃拟态（AURORA · LIQUID GLASS） | 极光弥散渐变做锁屏，玻璃卡片从药丸里长出来，一颗玻璃球掠过时钟，真实地折射、放大、色散。 | 折射色散、SDF 融合、液态玻璃 |
| 11 | 几何构成 包豪斯（BAUHAUS · ANAMORPHIC） | 二十块上漆的胶合板悬在白色影棚里，像一组抽象雕塑。镜头绕到唯一的那个角度，所有碎片严丝合缝，拼成一张包豪斯海报。 | 错觉对齐、光线追踪、120 BPM |
| 12 | 复古 Synthwave（SYNTHWAVE · VHS） | 贴着霓虹山谷低飞：发光网格、条纹落日、棕榈掠过。铬金大字和霓虹手写体砸进来，整帧再过一遍录像带。 | 光线步进地形、VHS 后期、霓虹光晕 |
| 13 | 像素风（PIXEL ART） | 304×171 的画布，每个像素都由代码摆放：抖动渐变、色彩循环瀑布、提灯照亮森林，推门通关。 | 抖动渐变、色彩循环、视差卷轴 |
| 14 | 液态流动（LIQUID MOTION） | 一滴液态金属落进暗场：皇冠水花、融合、升起，最后凝成一枚镜面播放键。 | 光线步进、液态金属、高速慢放 |
| 15 | 综艺花字（VARIETY CAPTIONS） | 多层描边、拟声字、表情贴纸、卡点推镜和闪白，把一颗煎蛋拍成综艺名场面。 | 多层描边、拟声字、卡点推镜 |
| 16 | 真实页面 2.5D 推镜（PAGE CAMERA） | 把真实的剪辑软件拆成悬浮图层，景深在层间切换；光标点下「AI 一键成片」，素材飞上时间线，镜头推进监视器。 | CSS 3D 图层、景深切换、光标演示 |
| 17 | 数据新闻 编辑风（EDITORIAL DATA） | 一整版排好的报纸专题：衬线大标题、双栏正文、自己画出来的折线图、数字滚动和荧光笔。镜头像读者的视线一样游走。 | 真实排版、图表生长、镜头阅读 |
| 18 | 水墨国风（INK WASH） | 一滴墨落在宣纸上晕成远山，再落笔松石与渔舟，镜头推进画里，最后钤上朱印「肖雄」。 | 墨晕扩散、宣纸纹理、朱印落款 |
| 19 | 黏土定格（CLAYMATION） | 三团彩泥揉成一只小知更鸟，每秒 12 帧定格，指纹和手作的抖动都留在画面里。 | 定格 12fps、彩泥质感、微距景深 |
| 20 | 蓝图工程图（BLUEPRINT） | 一支播客麦克风的爆炸图：轮廓线、尺寸标注和引线跟着零件走；零件组装好，扫描线一过，图纸变成真实的产品。 | 爆炸视图、尺寸标注、图纸变实物 |
